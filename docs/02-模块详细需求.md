> 本文档描述每个页面的**布局区块、交互行为、字段结构、状态与边界**。
> 所有数值、名称、编号均需与本文一致；未给出的细节可按常识补全，但不得与本文冲突。

阅读约定：
- `P0` 功能必须完整可交互，不允许只画静态图。
- 每个列表页都必须实现：加载骨架、空态、筛选无结果态、分页、排序（至少 2 列）。
- 每个详情页都必须实现：返回、面包屑、标题区（名称 + 状态标签 + 操作按钮组）。

### 园区三维缩略

- three.js 渲染简化版园区（LOD2，仅体块 + 道路 + 水体），自动缓慢旋转（0.02 rad/s），鼠标拖拽可手动旋转。
- 建筑上方悬浮标签：名称 + 复刻状态（已完成/进行中/待复刻），使用 CSS2DRenderer 或 3D 精灵。
- 点击建筑 → 右下角浮出信息卡（名称、面积、层数、模型精度、最近更新），卡片内"进入三维"按钮跳 `/recon/viewer?focus=B-02`。
- 右上角"全屏查看"按钮 → `/recon/viewer`。
- 性能预算：该图单独使用低配渲染器，限制像素比 1.5，关闭阴影。

### 风险告警流

- 竖向列表，每条：等级色条（高/中/低）+ 标题 + 时间 + 来源模块 + "去处理"。
- 自动滚动（每 4 s 上移一条），hover 暂停。
- 数据 8 条，至少包含：点云配准超限、设备离线、交付逾期、纹理缺失、巡检未执行、工单超时、存储水位、精度复检不合格。
- 点击"去处理"跳转到对应详情页并高亮。

### 6.2.2 新建采集任务（抽屉，宽 680px）

字段：任务名称*、采集类型*、采集区域*（级联：园区→分区→建筑）、使用设备*、操作员*、计划开始/结束*、航高（仅无人机）、GSD、航向/旁向重叠度、天气备注、空域申请编号、备注。
校验：结束时间晚于开始；航高 50-300 m；重叠度 60-90%。
提交后：Toast 成功 → 列表顶部插入新记录（状态"待开始"）→ 持久化。

### 6.2.3 任务详情 `/data/tasks/:id`

四个 Tab：

**概览**
- 左侧：二维航线示意图（SVG）。绘制园区轮廓、任务区域多边形（半透明填充）、航点圆点、航线折线、起降点图标、指北针、比例尺 1:2000。
- 右侧：参数表（12 项）、设备卡（型号、SN、固件、累计飞行时长）、天气（晴，22℃，东南风 3 级，能见度 12 km）。

**成果**
- 成果列表：文件夹树（原始照片 / POS 数据 / 点云 / 空三报告 / 模型切片）+ 文件表格（名称、类型、大小、校验状态）。
- 上传区：拖拽上传，模拟进度（2-6 s），完成后状态变"已校验"，并更新任务数据量。

**质检**
- 检查点残差表：128 个检查点，列（点号、X 残差、Y 残差、Z 残差、是否超限）。中误差 2.4 cm，最大 4.8 cm，超限 0 个。
- 覆盖率热力图：SVG 网格，绿色 >95%，黄色 85-95%，红色 <85%（至少 3 个红格）。

**日志**
- 时间线：创建、设备起飞、返航、数据回传、质检发起、质检通过。

### 6.2.4 数据集管理 `/data/datasets`

左侧：数据集树（按项目 → 数据类型 → 批次）。右侧：数据集卡片网格（68 条）。
卡片：类型图标、名称、格式徽标（OSGB / LAS / IFC / glTF / JPG）、大小、点数或三角面数、坐标系、更新时间、共享范围。
操作：预览（跳三维）、下载（模拟）、详情抽屉（元数据表 20 项、血缘关系图：原始数据 → 处理任务 → 成果）。

### 6.2.5 质量与精度 `/data/quality`

- 顶部 4 个指标：检查点总数 128、平面中误差 2.4 cm、高程中误差 3.1 cm、粗差率 0.00%。
- 残差分布图：散点图（X 残差 vs Y 残差），带 ±3 cm 阈值圆。
- 按批次统计表：批次、点数、中误差、超限数、结论。
- 精度趋势：近 8 批次折线，含阈值参考线。

### 6.4.2 空间标定 `/mr/calibration`

三步向导（Stepper）：

**Step 1 选择方式**（三张卡片）
1. 二维码 Marker 标定 — 精度 ±8 mm，适合固定工位
2. 点云配准标定 — 精度 ±5 mm，适合大空间

**Step 2 执行**

**Step 3 结果**
- 大数字：配准 RMS 12 mm，最大误差 21 mm，配准点 26 个，耗时 48 s。
- 残差表：点号、X/Y/Z 残差、是否超限（阈值 15 mm），超限 2 个标红。
- 结论：合格 / 需重标。附"生成标定报告"。
- 保存后进入标定记录列表。

## 6.9 全局组件与交互规范

3. **Toast**：成功/失败/警告三种，2.5 s 自动消失，右上角堆叠。
4. **确认弹窗**：删除、回滚、结束会话等破坏性操作必须二次确认，按钮文案明确（"确认删除"而非"确定"）。

6. **骨架屏**：列表/图表加载时使用，不用转圈。
7. **数字动效**：KPI 数字入场 600 ms 滚动，图表首次渲染 800 ms 动画。
