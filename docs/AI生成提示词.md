# 一、项目基本信息

# 二、硬性约束（违反即不合格）

1. **零网络请求**：不允许 `fetch` / `XHR` / WebSocket / SSE 调用任何接口。不许引用 CDN 字体、外链图片、在线图标库、在线占位图。所有图标用 `@ant-design/icons` 或内联 SVG，所有封面用 CSS 渐变或本地 SVG 生成。
2. **零桌面端依赖**：不出现 electron、@tauri-apps、fs、path、child_process、require 等。
3. **数据必须 Mock 且真实**：数量要够、字段要全、命名要像真实业务。禁止 lorem ipsum、禁止 "测试1/测试2/示例数据/xxx"、禁止所有卡片内容雷同。
4. **不许有死链和空壳页面**：每个按钮、菜单、表格行操作、Tab 都必须有真实响应（跳转、抽屉、弹窗、Toast）。不允许"点了没反应"，也不允许用 `alert()` 代替界面。
5. **不许有 TODO / 占位文案 / "功能开发中"**（除明确标注 P2 的"数字人播报"可显示"即将上线"）。
6. **必须能构建成功**：`npm run build` 零错误，TypeScript strict 模式下无 `@ts-ignore`、无大面积 `any`。
7. **代码要能维护**：单文件不超过 300 行，类型完整，公共能力抽组件，禁止把 200 条 mock 数据内联在页面组件里。
