## 3. 三维引擎实现规范

### 3.1 场景构建（程序化，不加载外部模型文件）

园区必须由代码生成，禁止引用任何 `.glb/.gltf/.osgb` 外部资源（避免体积与版权问题）。

`src/mock/generators/scene.ts` 导出：

```ts
export type SceneNode = {
  id: string
  name: string
  type: 'zone' | 'building' | 'component' | 'pipe' | 'tank' | 'crane' | 'road' | 'water'
  parentId: string | null
  bbox: { min: [number, number, number]; max: [number, number, number] }
  transform: { position: [number, number, number]; rotationY: number }
  meta: Record<string, string | number>
}
export function buildParkScene(): SceneNode[]
```

坐标约定：
- 单位 = 米，Y 轴向上，园区中心为原点 `(0, 0, 0)`。
- 局部坐标 → CGCS2000：`X = 3453210.456 + localX`，`Y = 40512880.132 - localZ`（注意 Z 轴向南）。
- 经纬度换算（用于状态栏显示，允许 ±1 m 误差）：
  - `lat = 30.2841 + localZ / 111320`
  - `lng = 120.1526 + localX / (111320 * cos(30.2841°))`

### 3.2 建筑生成规则

```ts
type BuildingSpec = {
  code: string          // 'A-01'
  name: string          // '装配车间一'
  zone: string          // 'A 区 智能装配'
  size: [number, number, number]   // 长 宽 高
  floors: number
  roofType: 'flat' | 'sawtooth' | 'gable'
  wallColor: string
  roofColor: string
  hasDock?: boolean     // 装卸月台
  hasChimney?: boolean  // 烟囱
  windowsPerFloor: number
}
```

渲染要求：
- 墙体：`BoxGeometry`，`MeshStandardMaterial`（roughness 0.85, metalness 0.05）。
- 窗：**必须用 `InstancedMesh`** 统一渲染（单栋楼的窗户合并为一个 instanced mesh），颜色 `#7DD3FC`，带轻微 emissive 模拟玻璃反光。
- 屋顶：平屋顶加女儿墙；锯齿屋顶用多个旋转 30° 的斜面拼接；坡屋顶用 `ExtrudeGeometry` 或两个斜面 Box。
- 少量细节：屋顶空调机组（小 Box）、爬梯（细长 Box）、雨棚（薄板）、门（深色平面）。
- 文保建筑：红砖墙 `#A85A48`，坡屋顶 `#4B5563`，32 m 烟囱（`CylinderGeometry` 收分），外墙加拱形窗（用 Shape + ExtrudeGeometry 挖洞）。
- 储罐：`CylinderGeometry`，顶部加环形护栏（`TorusGeometry`）。
- 管廊：沿 `CatmullRomCurve3` 生成管道（`TubeGeometry`），架空 4.5 m，立柱每 12 m 一根。
- 码头门机：立柱 + 横梁 + 吊臂（Box 组合），可带缓慢旋转动画（0.05 rad/s）。
- 道路：用 `PlaneGeometry` 贴 Canvas 生成的沥青纹理（含车道线），略高于地面 0.02 m 避免 z-fighting。
- 水体：`PlaneGeometry` + 半透明蓝色材质 + 简单法线扰动（顶点着色器或 sin 波动）。
- 绿化：`InstancedMesh` 渲染 200 棵树（圆锥 + 圆柱），随机但在道路两侧成排。
- 车辆/集装箱：`InstancedMesh`，20 个，增强真实感。

**性能红线**：整个园区的 drawcall 必须 ≤ 400。所有重复物体（窗、树、路灯、车、集装箱、护栏柱）必须实例化。

### 3.3 点云

```ts
// 按建筑轮廓采样，而非纯随机
export function samplePointCloud(nodes: SceneNode[], count = 200_000): Float32Array
```
- 每个建筑按表面积分配点数（墙面 70%、屋面 20%、地面 10%），点沿表面抖动 ±2 cm。
- `BufferGeometry` + `PointsMaterial`（size 1.2, sizeAttenuation true, vertexColors true）。
- 三种着色模式通过重算 `color` attribute 实现：
  - RGB：基础 `#94A3B8` + 5% 噪点
  - 高程：Y 从 8.5→12.3 映射 `#1E3A8A → #22D3EE → #F59E0B → #EF4444`
  - 强度：0-255 映射灰度到橙
- 必须提供"点大小"和"透明度"两个滑块。

### 3.4 相机与交互

- 默认 `PerspectiveCamera` fov 45, near 1, far 6000。
- `OrbitControls`：左键旋转、右键平移、滚轮缩放，`maxPolarAngle = Math.PI / 2.05`（禁止钻到地下），`minDistance 20`，`maxDistance 2200`，开启阻尼 0.08。
- 聚焦动画：用 `useFrame` 做 1.2 s easeInOutCubic 插值，同时插值 target。
- 第一人称漫游：WASD + 鼠标（PointerLock 可不用，改为按住拖拽转视角，避免锁鼠影响演示），保持相机高度 1.7 m，限制在园区范围内。
- 拾取：`Raycaster`，只对可拾取对象（建筑主体、构件、标注）启用，`raycaster.params.Points.threshold = 0.8`。
- 鼠标位置实时换算世界坐标（用一条从相机出发的射线与地面/建筑求交），显示在状态栏。

### 3.5 剖切 / 对比 / 标注

- 剖切：`renderer.localClippingEnabled = true`，用 `THREE.Plane`，滑块直接改 `plane.constant`。盒式用 6 个 plane（`material.clippingPlanes` 数组）。
- 对比：BIM 模型用 `MeshBasicMaterial` 线框 + 半透明；实景模型透明度用 `material.opacity`。偏差色谱通过对 BIM 顶点写入 `color` attribute（按顶点到最近实景面的距离映射）实现；距离可预生成伪随机但按建筑分区的合理值（如屋面偏差大、墙面偏差小）。
- 标注：世界坐标存 `{x,y,z}`，渲染为 `Sprite`（Canvas 生成的圆形图标 + 序号）。点击用 `onClick` + `stopPropagation`。

### 3.6 光照与氛围

- `HemisphereLight(0x8EC5FF, 0x0B1220, 0.6)`
- `DirectionalLight(0xFFFFFF, 1.6)`，位置 `(600, 900, 400)`，开启阴影（`mapSize 2048`，`camera` 范围覆盖园区）。
- 环境贴图：用 `RoomEnvironment` 或 Canvas 渐变生成 `PMREMGenerator` 贴图，**不加载 HDR 文件**。
- 雾：`FogExp2(0x070B14, 0.00022)`，营造纵深。
- 天空：大球体 + 顶点着色渐变（深蓝 `#0B1220` → 青灰 `#1E3A5F`），或纯色 + 渐变背景 CSS。
- 后处理：可选加 `Bloom`（阈值 0.85，强度 0.35），若性能不足可关闭。**不得使用需要额外大依赖的 EffectComposer 方案**，drei 的 `Effects` 足够。

### 3.7 性能与降级

| 措施 | 要求 |
|---|---|
| 像素比 | `Math.min(window.devicePixelRatio, 2)` |
| 帧循环 | `frameloop="demand"` 用于静态页，交互时切换 `always` |
| 几何复用 | 相同尺寸建筑共享 geometry |
| 材质复用 | 按颜色缓存 material |
| LOD | 距离 > 800 m 隐藏窗户与细节；> 1500 m 只显示体块 |
| 卸载 | 离开路由必须释放 renderer、geometry、texture、监听器 |
| 降级 | WebGL2 不可用 → 展示静态 SVG 园区图 + 提示卡片 |
| 低性能 | 连续 3 s FPS < 25 → 自动关闭阴影与 Bloom，并 Toast 提示"已切换性能模式" |

## 5. Mock 数据规范

### 5.1 原则

1. **确定性**：使用固定种子的伪随机（`mulberry32(20261019)`），每次刷新数据一致，便于演示与截图。
2. **关联一致**：设备 → 场景 → 标定 → 会话 → 工单，外键必须能互相查到；统计数字必须由明细聚合得出，不得硬编码两套。
3. **时间连续**：所有时间落在 `2025-03-10` ~ `2026-10-19`，符合工作日规律（周末数据量下降 60%），最近 7 天有数据。
4. **量级真实**：面积、体积、点数、金额、时长符合行业常识（见 01 文档设定表）。
5. **边界存在**：超期、离线、不合格、低置信度、无附件等异常数据占 8%~12%，且分散在不同页面。
6. **文案真实**：备注、验收意见、缺陷描述必须是人写的口吻，不能是"测试数据 1/2/3"。

### 5.4 数据访问层

```ts
// services/request.ts
export async function mockRequest<T>(data: T, delay = 260): Promise<T> {
  await new Promise(r => setTimeout(r, delay))
  return structuredClone(data)
}
```
- 列表接口统一返回 `{ list, total, page, pageSize }`。
- 写操作（新增/编辑/删除/状态流转）必须：更新内存 store → 写 localStorage → 返回新数据。刷新后仍在。
- localStorage key 统一前缀 `mirrorfield.`，例如 `mirrorfield.tasks`、`mirrorfield.auth`。
- 所有 service 函数签名带 TS 类型，禁止 `any`。
- 提供 `resetDemoData()`，在参数设置页可调用，清空 localStorage 并重建种子。

### 5.5 禁止

- 禁止在组件里直接 import `seeds/*`（必须经过 service，便于未来替换真实接口）。
- 禁止用 `Math.random()` 直接生成展示数据（不可复现）。
- 禁止出现"lorem ipsum"、英文占位、`测试1`、`TODO`、`xxx`。
- 禁止用 1/2/3 递增的时间戳（要看起来像真实时间分布）。

**图表色板**（顺序使用）：`#22D3EE` `#6366F1` `#34D399` `#FBBF24` `#F472B6` `#A78BFA` `#FB923C` `#38BDF8`

### 6.2 字体与排版

```css
font-family: "Inter", "HarmonyOS Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
```
- 不引入 Web Font（离线要求），依赖系统字体。
- 数字：KPI 大数字用 `font-variant-numeric: tabular-nums`，字重 600。
- 字号阶梯：12（辅助）/ 13（表格）/ 14（正文）/ 16（小标题）/ 20（卡片标题）/ 28（页面标题）/ 40（KPI）。
- 行高：正文 1.6，标题 1.3。
- 字间距：中文标题 `0.02em`，英文/数字 `0`。

### 6.3 布局与间距

- 侧栏 232px（折叠 64px），顶栏 56px，内容区 padding 20px，卡片间距 16px。
- 栅格 12 列，`gap 16px`。
- 圆角：卡片 10px，按钮 6px，标签 4px，输入框 6px。
- 阴影：卡片 `0 1px 2px rgba(0,0,0,.24), 0 8px 24px -12px rgba(0,0,0,.5)`；浮层更重。
- 卡片必须有 1px 边框，hover 时边框变 `--border-strong` 并轻微上浮。

### 6.4 组件规范

**状态标签**：统一 6 种语义色（进行中=青、已完成/合格=绿、待处理=灰、警告=黄、超期/异常=红、草稿=靛）。禁止随意新增颜色。

**表格**：
- 表头 `--bg-elevated`，13px，`--text-secondary`，字重 500。
- 行高 48px，斑马纹（偶数行 `rgba(255,255,255,0.02)`），hover 高亮。
- 分页默认 20 条，可选 20/50/100。
- 重要列固定在左侧（编号、名称），操作列固定右侧。

**按钮**：主按钮填充 `--brand`，文字深色；次按钮描边；文字按钮仅用于表格操作。破坏性操作必须红色 + 二次确认。

**图表**：
- 网格线 `rgba(148,163,184,0.10)`，虚线。
- 坐标轴文字 12px，`--text-tertiary`。
- tooltip 深色背景 + 1px 边框 + 圆角 8，显示系列名与值。
- 所有图表必须有标题与单位，禁止裸图。

**三维浮层**：半透明 `rgba(14,21,38,0.86)` + `backdrop-filter: blur(12px)`，边框 1px，圆角 12。

### 6.5 动效

- 时长 150-250ms，缓动 `cubic-bezier(0.4, 0, 0.2, 1)`。
- 页面切换：内容区淡入 + 上移 8px（200ms），不做整页转场。
- 数字滚动：600ms。
- 三维相机飞行：1200ms。
- 禁止无限循环的装饰性动画（除三维场景自身的缓慢旋转）。

### 6.6 文案

- 全中文，术语按 01 文档术语表。
- 按钮用动词开头："新建任务""导出报告""发起协同"。
- 空态文案要具体："暂无巡检记录，创建第一个巡检计划"。
- 错误提示要可行动："配准 RMS 4.7 mm 超出阈值 3 mm，建议重新采集 2 个检查点后复标"。
- 禁止"敬请期待""功能开发中""暂未实现"。

## 7. 工程规范

### 7.1 代码

- TS `strict: true`，`noUnusedLocals`、`noUnusedParameters` 开启。
- 组件：函数组件 + hooks，禁止 class 组件。
- 命名：组件 `PascalCase`，文件 `kebab-case.tsx`，hooks `useXxx`，常量 `UPPER_SNAKE`，类型 `PascalCase`。
- 每个 feature 目录下 `index.ts` 统一导出。
- 单文件不超过 300 行，超出必须拆分（三维工具组件可到 400 行）。
- 禁止 `console.log` 残留（只允许 `console.warn/error` 用于真实异常）。
- 所有 `useEffect` 必须有清理函数（尤其是 three 的监听器与 RAF）。
- 三维组件内部状态用 `useRef`，避免每帧 `setState`。

### 7.2 路由

- 全部 `React.lazy` + `Suspense`，fallback 为骨架屏。
- 路由守卫读 `authStore.role`，无权限渲染 403 页。
- 三维页与编排页使用 `ImmersiveLayout`（隐藏侧栏）。

### 7.3 状态

| store | 内容 |
|---|---|
| `authStore` | 当前用户、角色、权限集合、登录态（persist） |
| `uiStore` | 侧栏折叠、主题、语言、全局搜索开关 |
| `sceneStore` | 当前场景、图层状态、选中对象、测量结果、标注列表 |
| `authoringStore` | 当前编排、节点、播放时间、选中节点 |
| `notificationStore` | 通知列表、未读数 |

- 持久化只用于 `authStore` 与 `uiStore`，其余内存态。

### 7.4 打包为桌面端的前置约束（本项目不写桌面端代码，但必须满足）

| 约束 | 具体要求 |
|---|---|
| 路由 | 必须 `HashRouter`，禁止 `BrowserRouter`（`file://` 下会 404） |
| 资源路径 | `vite.config.ts` 设 `base: './'`，所有图片/字体用相对路径或内联 |
| 无外网依赖 | 禁止任何 `https://` 资源引用（字体、图标、地图、图片、CDN） |
| 无 SSR | 不引入 Next.js，不使用 `document` 之外的 Node API |
| 无 Node 内置模块 | 禁止 `fs` / `path` / `child_process` |
| 无桌面端依赖 | 禁止 `electron` / `@tauri-apps/*` / `node-ipc` |
| 存储 | 只用 `localStorage`，不使用 IndexedDB 大文件（可选但非必需） |
| 窗口尺寸 | 最小 1280×800 布局不破；不使用 `100vh` 的移动端特有问题（用 `100dvh` 兜底） |
| 下载 | 导出文件用 `Blob` + `a[download]`，不用后端接口 |
| 深链接 | 分享链接用 `#/xxx` 形式，不用 `location.origin` 拼绝对地址 |
| 权限 | 不申请摄像头/麦克风真实权限（会弹窗），全部模拟 |

### 7.5 构建校验

- `npm run build` 必须零 TS 错误、零 ESLint error。
- 产物 `dist/index.html` 用 `file://` 直接打开可正常运行（路由、图片、三维全部正常）。
- `dist/assets` 中 three 相关 chunk 单独分包（`manualChunks`）。
- 首屏 JS gzip < 1.2 MB，three chunk gzip < 700 KB。
