# 1. 项目目标

构建一个名为「**数据云端协同优化传输平台**」的 Web 应用（产品代号 DataRelay，中文名「云枢」）。

它是一个企业级数据流转中枢：把分散在本地机房、边缘节点、公有云、私有云之间的数据，通过智能调度与传输优化（压缩、去重、分片并行、断点续传、智能路由）安全高效地送达目标，并支持多团队在统一空间内共享与协作。

# 2. 硬性约束（最高优先级，任何一条都不能违反）

1. **纯前端**：不写后端、不连数据库、不启动任何 server。

## 6.4 数据自洽规则（重要，别出现一眼假的数据）

- `transferredSize <= totalSize`，`progress = round(transferredSize / totalSize * 100)`
- `speedBps > 0` 仅当状态为 running / verifying，其余为 0
- `durationSec ≈ transferredSize / speedBps`
- `etaSec = (totalSize - transferredSize) / speedBps`
- 通道 `usedMbps` ≈ 其承载 running 任务速率之和（±20%）
- 节点 `usedTB < capacityTB`，`cpu`/`mem` 在 8%-92%
- 成功任务必须有 `finishedAt`；失败任务必须有 `errorCode` 与 `errorMessage`

## 7.7 优化策略 `/policies`

**列表**：卡片式。每张显示名称、场景标签、参数摘要（`zstd · 块级去重 · 64MB 分片 · 16 并发`）、引用任务数、预估节省（`↓38% 流量`，绿色）、启用开关、编辑/复制/删除。被引用时删除按钮禁用并 tooltip「有 N 个任务正在使用」。

**编辑器** `/policies/new`、`/policies/:id/edit`：左 2/3 表单 + 右 1/3 吸顶预估面板。

表单分区：
1. 压缩：算法（不压缩/gzip/lz4/zstd，每个选项下方标注压缩比与 CPU 开销）、级别滑块 1-9
2. 去重：关闭/文件级/块级、块大小 4/8/16MB、指纹有效期
3. 并行：分片大小滑块（16/32/64/128MB）、并发数 1-64、多路复用开关
4. 限速与调度：带宽上限、时间段限速（可添加多条规则）、优先级
5. 可靠性：重试次数、重试间隔、断点续传、弱网 FEC 纠错
6. 校验：不校验/MD5/SHA-256/CRC32C、完成后自动校验

**预估面板**（参数变化 200ms 防抖重算，纯前端公式）：
- 大数字「预估加速比 3.4x」
- 三条对比：传输耗时 42min → 12min；消耗流量 1.2TB → 744GB；CPU 占用 18%
- 一行智能建议文案，按参数条件切换（如并发接近通道上限时提示「继续提升并发收益有限」）

计算规则固定如下：

```
ratio = { none:1.0, gzip:0.42, lz4:0.58, zstd:0.36 }[compression] - (level - 5) * 0.005
dedup = { none:0, file:0.08, block:0.22 }[dedup]
effective = totalSize * ratio * (1 - dedup)
speedup = min(concurrency / 4, 6) * (chunkSizeMB >= 64 ? 1.15 : 1)
耗时秒 = effective / (bandwidthMbps * 0.125 * 1024 * 1024) / speedup
cpu = 12 + level * 3 + (dedup === 'block' ? 18 : 0) + concurrency * 0.8
```

底部：取消 / 保存 / 保存并应用。
